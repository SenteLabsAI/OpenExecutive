# Weekly Review

A weekly review is thirty minutes that decides whether next week is spent on what matters or on whatever shouts loudest. It works the same whether you run a business, lead a function inside a larger organisation, or work independently: look back honestly, then choose.

## 1. Grade every goal against its target

- Grade from evidence — the current value against the target — never from how the week felt.
- **On track**: the current pace reaches the target by the period's end.
- **At risk**: it reaches the target only if something changes soon.
- **Off track**: at the current pace it misses, and a plan is needed now.
- Name what moved the grade in one sentence. A goal with no new evidence keeps its grade; say so rather than guessing.

## 2. Clear what is due

- List every commitment that is overdue or due in the next seven days — the ones you made and the ones you were asked for.
- For each overdue one, decide now: do it first thing next week, renegotiate the date, or drop it and tell the person. An overdue promise left silent costs more trust than a moved date.

## 3. Revive or retire what went quiet

- A project with no update in a week is either blocked, done, or no longer a priority.
- For each: name the one next step that unblocks it, mark it done, or pause it deliberately. "Active" should mean active.

## 4. Learn from decisions

- Read this week's decisions back: are any already in doubt?
- Take up to three decisions from a month or more ago and ask how they turned out — what happened, and whether you would decide the same way again. Record the answer against the decision so the next call of the same kind starts from evidence.

## 5. Pick next week's top three

Choose at most three outcomes for next week, in this order of preference:

1. What rescues an off-track or at-risk goal.
2. What keeps a promise that is overdue or due.
3. What unblocks a project that went quiet.

Each pick is one concrete thing to move, with the goal, commitment, project or decision it serves. If a candidate cannot name the goal it moves, it is not a top-three item. Three is a ceiling, not a target: two real priorities beat three padded ones.

## Anti-patterns

- Grading on effort instead of results ("we worked hard on it" is not on track).
- Carrying the same overdue item week after week without renegotiating it.
- A top three that restates the goal list instead of naming the next move.
- Inventing numbers, dates or owners the review does not contain.
